# Migration Agent Documentation

This folder is the markdown documentation hub for the Codebase-Wide Version
Migration & Refactoring Agent.

## Documents

| Document | Purpose |
|---|---|
| [High-Level Design](./HLD.md) | System boundaries, modules, responsibilities, and deployment view |
| [Low-Level Design](./LLD.md) | Core data contracts, processing stages, and implementation details |
| [Sequence Flows](./SEQUENCES.md) | End-to-end and batch-level Mermaid sequence diagrams |
| [Data Flow](./DATA_FLOW.md) | Inputs, intermediate artifacts, outputs, and trust boundaries |
| [Security](./SECURITY.md) | Threat model, controls, secrets, sandboxing, and review checklist |
| [Input Specification](./INPUT_SPECIFICATION.md) | Migration spec JSON format and CLI inputs |
| [Installation Guide](./INSTALLATION.md) | Windows, Linux/macOS, validation, and troubleshooting |

The original academic design documents remain in [`../design/`](../design/).
These markdown documents provide an implementation-oriented reference and
identify incomplete modules rather than presenting planned behavior as
available functionality.
